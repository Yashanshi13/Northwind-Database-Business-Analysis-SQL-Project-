# 📊 Northwind Database Business Analysis (SQL Project)

## 📝 Project Overview

This project involves comprehensive business analysis using the **Northwind Traders** database, a sample ERP dataset containing customers, orders, products, suppliers, employees, and shipping data.

The objective of this project is to analyze sales performance, customer behavior, product trends, and regional performance using SQL queries to derive meaningful business insights.

---

## 🎯 Business Objectives

* Analyze overall sales and revenue performance
* Identify top-performing products and categories
* Determine high-value customers
* Analyze country-wise and region-wise sales trends
* Evaluate employee sales performance
* Discover monthly and yearly revenue trends

---

## 🗂️ Database Structure

The Northwind database includes the following key tables:

* Customers
* Orders
* Order_Details
* Products
* Categories
* Suppliers
* Employees
* Shippers
* Territories
* Region

These tables were connected using primary and foreign keys to perform relational analysis.

---

## 🔍 Key Analysis Performed

* Total revenue calculation using `SUM()`
* Customer-wise and country-wise sales analysis
* Product and category performance evaluation
* Multi-table `JOIN` operations
* Revenue trend analysis (Monthly & Yearly)
* Ranking top customers/products using `RANK()` and `DENSE_RANK()`
* Advanced filtering using `GROUP BY` and `HAVING`

---

## 📈 Key Insights

* Identified top revenue-generating products and categories
* Discovered high-performing customers and regions
* Analyzed employee sales contribution
* Observed seasonal trends in sales performance
